## TASK 3: CREATE server.py

### Flask Application Features
The `server.py` file implements:

#### Route 1: GET /
- Renders the HTML interface (index.html)
- Provides the user-facing web application
- Serves static HTML template

#### Route 2: POST /emotion_detection
- REST API endpoint for emotion detection
- Accepts JSON: `{"textToAnalyze": "text here"}`
- Returns JSON response with emotion scores
- Returns 400 status for invalid/empty input
- Error handling for missing text parameter

## TASK 5: CREATE EmotionDetection/emotion_detection.py

### Function: emotion_detector(text_to_analyse)

#### Parameters:
- `text_to_analyse` (str): Text to analyze for emotions

#### Returns:
- **On Success (200)**: Dictionary with structure:
```python
{
    "anger": float (0.0-1.0),
    "disgust": float (0.0-1.0),
    "fear": float (0.0-1.0),
    "joy": float (0.0-1.0),
    "sadness": float (0.0-1.0),
    "dominant_emotion": str (emotion with highest score)
}
```

- **On Empty/Blank Input (400)**: `None`
- **On Null Input (400)**: `None`

#### Key Implementation Details:
1. **Input Validation**
   - Returns `None` for empty strings
   - Returns `None` for blank/whitespace-only strings
   - Returns `None` for `None` input

2. **IBM Watson NLP Integration**
   - Calls Watson NLP API endpoint
   - Sends text with emotion feature request
   - Parses emotion response
   - Calculates dominant emotion using `max()` function

3. **Error Handling**
   - Graceful handling of API errors
   - Returns `None` on connection failures
   - Returns `None` on timeout
   - Handles 400 status codes from API
